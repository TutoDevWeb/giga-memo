# Contexte du projet giga-memo

- **Framework** : Symfony 7.4
- **Frontend** : AssetMapper, Twig, Stimulus
- **Database** : Doctrine ORM, MySQL
- **Objectif** : Application de révision / mémoire (fiches, répétition espacée)
- **Conventions** : PSR-12, code et commentaires en français
